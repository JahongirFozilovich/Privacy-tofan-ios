Privacy Policy

Effective Date: 25.03.2026

Tofan Workout (“we”, “our”, or “us”) operates the Tofan Workout mobile application. This Privacy Policy explains how we collect, use, and protect your information.

1. Information We Collect

Account Information

  • Username
  • Password (securely hashed)

Profile Information

  • First name (optional)
  • Last name (optional)
  • Age
  • Gender
  • Weight
  • Height

Media Data

  • Images selected or captured by the user for AI meal analysis (optional)

2. How We Use Your Data

  • Provide workout and fitness features
  • Analyze meal images for nutrition estimation
  • Maintain user accounts
  • Improve app performance

3. Data Storage

Your data is stored securely using Firebase services provided by Google. Access is restricted using Firebase security rules.

4. Permissions Used

  • Activity Recognition
  • Camera
  • Storage / Media Access
  • Foreground Service
  • Boot Completed
  • Internet Access
  • Notifications
  • Vibration

5. Data Deletion

Users can request account deletion directly inside the app at any time.

  • All user profile data is permanently removed from Firebase
  • All fitness and activity data is deleted
  • All related media data is removed

Deletion is permanent and cannot be undone.

6. Data Sharing

We do not sell or rent personal data. Data is only processed within Firebase infrastructure or when required by law.

7. Children’s Privacy

This app is not intended for children under 13. We do not knowingly collect data from children under 13.

8. Your Rights

  • Access your data
  • Request deletion
  • Stop using the app anytime
